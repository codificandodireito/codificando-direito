# Codificando Direito

Site de oportunidades gratuitas de educação do perfil [@codificandodireito](https://www.instagram.com/codificandodireito/).

Endereço: https://codificandodireito.netlify.app

## Estrutura

| Arquivo | Para que serve |
|---|---|
| `index.html` | Layout e funcionamento da página |
| `oportunidades.js` | **Lista de oportunidades** (único arquivo alterado nas atualizações semanais) |
| `sitemap.xml`, `robots.txt` | Leitura do site pelo Google |
| `og-image.png`, `favicon.svg`, `apple-touch-icon.png` | Imagem de compartilhamento e ícones |

## Atualização

Toda semana uma atualização automática propõe mudanças em `oportunidades.js`
(novas inscrições, remoção das encerradas). Depois de aprovada, o Netlify publica o site sozinho.
